01功能

状态桌宠

多个会话一起汇总：等你 > 出错 > 完成 > 工作中 > 空闲 > 离线，桌宠永远显示最需要你看的那个。

思考气泡

按当前工具说一句话，比如「📖 翻翻文件…」「⌨️ 跑个命令」。只看工具名，从不读取提示词。

完成小结

一轮结束时报告用时和工具调用次数，然后撒一把星星。

等你提醒

等你 30 秒跳一跳，2 分钟在消息框里留言，处理后自动撤掉。不弹系统通知。

戳一戳 · 额度

戳她会害羞或鼓脸；用官方 Claude 登录时，头顶浮出 5 小时窗口和本周额度。

AFK 挂机

关掉所有闲时提示和闲聊，只保留集群作业监督，适合离开电脑时。

切换模型

写 ~/.claude/settings.json 的 model：默认 / Opus / Sonnet / Haiku / Opus Plan。

切换供应商

只覆盖 env.ANTHROPIC_*，其它设置原样保留；每次写入前自动备份。

Token 用量

增量解析会话记录：今日、近 5 小时、近 7 天、按模型、最近会话。

02每种工具一套动画

动画Claude Code 工具气泡

Claude 一秒内常换好几个工具，每个动画至少停留 3 秒，画面不会乱跳。

03集群作业监督

挂在服务器上的计算作业，不用守着终端看。ClaudeStatus 定时用 SSH 读一次集群上的摘要脚本，这一步不调用模型、不花 token；只有真遇到问题，才在后台唤起 Claude。

标签角标
桌宠标签上直接显示 ⚙ 运行+排队、⚠ 待处理，Claude 在处理时显示 🔧。
有事叫你
出现没人处理的问题时，空闲的桌宠会举手提醒，标签变成「集群待处理」。
自动唤起
待处理事件自动交给后台的 Claude 去查、去修；失败有重试上限，每天有次数上限。
结果通知
批次完成、按日期打包好的结果包（批数、文件数、大小、路径）写进消息框，留到你关掉为止。
报告与续聊
每次唤起都留下报告、花费和结论（完成 / 需要你 / 失败），可以一键在终端里接着那次对话。
AFK 也在
开启 AFK 后其它提示全部安静，集群监督照常运行。

04工作原理

Claude Code Hooks

每个事件调用一次小脚本，只记事件名、工具名、目录和时间戳。

会话状态文件

写到 ~/.claudestatus/sessions/<id>.json，原子写入，不阻塞 Claude。

汇总

多会话按优先级合并；窗口关掉没发 SessionEnd 也会按进程判断清理。

桌宠

播放对应动画和气泡；像素统一在 192×256 网格，屏幕上 1 像素对 1 像素。

05安装

npm install npm start # 或双击 start.bat npm run dist # 打包成 Windows 便携版 exe
  1. 1

    首次启动在面板里点「一键安装」状态 Hook，然后新开一个 Claude Code 会话。

  2. 2

    拖动移动桌宠，双击打开面板，右键快速切换模型和供应商、开关 AFK 和闲聊气泡。

  3. 3

    卸载 Hook 只移除带 claudestatus 标记的条目，你自己的 Hook 不受影响。
